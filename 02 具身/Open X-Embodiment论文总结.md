# Open X-Embodiment 论文总结

## 1. 论文信息与核心结论

| 项目 | 内容 |
| --- | --- |
| 论文名称 | Open X-Embodiment: Robotic Learning Datasets and RT-X Models |
| 作者 | Open X-Embodiment Collaboration |
| 版本依据 | 本地 PDF，arXiv:2310.08864v9，2025 年 5 月 14 日 |
| 研究方向 | 跨具身机器人学习、模仿学习、视觉语言动作模型 |
| 核心资源 | Open X-Embodiment 数据集、RT-X 模型与数据使用工具 |

**核心结论是，多种机器人的经验可以通过联合训练产生正迁移，尤其有助于数据较少的平台，并能将其他平台数据中的部分技能迁移到目标机器人。** 论文同时展示了模型容量、预训练和数据构成对收益的影响。

本文根据本地论文正文整理，表格数值对应原文 Table I、Table II。第 7 节为基于论文的数据工程解读。

## 2. 研究背景与问题

机器人学习数据通常分散在不同实验室，覆盖的机器人、场景、物体和任务各不相同。单个平台的数据采集成本较高，任务覆盖范围也有限。

跨平台共享数据存在三类困难。

- **观测差异**。相机数量、安装位置、画面分辨率和传感器类型不同。
- **动作差异**。控制维度、坐标系、控制频率以及位置或速度控制方式不同。
- **数据分布差异**。任务类型、物体、环境和示范规模存在明显差异。

论文研究以下问题。

1. 联合训练多个机器人的数据，能否提高各平台已有任务的成功率？
2. 其他平台的数据能否帮助目标机器人执行其自身数据中缺少的技能？
3. 模型容量、视觉语言预训练和数据构成如何影响迁移效果？

## 3. Open X-Embodiment 数据集

### 3.1 数据规模

| 指标 | 论文报告 |
| --- | --- |
| 真实机器人轨迹 | 超过 100 万条 |
| 机器人形态 | 22 种 |
| 汇集的已有数据集 | 60 个 |
| 数据来源实验室 | 34 个 |
| 合作机构 | 21 家 |
| 技能类别 | 527 类 |

轨迹表示一次执行过程中的连续观测和动作。数据覆盖单机械臂、双臂机器人和四足机器人等形态，任务中抓取与放置占比较高，也包含擦拭、装配等长尾技能。

**论文模型训练使用的混合数据覆盖 9 种机器人形态。** 22 种形态是数据仓库规模，具体实验的训练范围需要按论文 §IV-C 理解。作者解释，数据仓库在实验开展后继续扩展。

### 3.2 数据格式

数据统一采用 RLDS 格式，以 TFRecord 文件存储，按 episode 组织执行轨迹。该格式能够容纳不同观测模态和动作空间，有利于共享读取工具与并行加载流程。

需要区分数据仓库支持的模态与实验模型使用的输入。仓库可以容纳多相机、深度和点云等数据，本文实验选择每个数据集的一个相机视角作为视觉输入。

本节对应论文 §III、§IV-A 和 §IV-C。

## 4. 方法与模型

### 4.1 观测与动作的粗粒度对齐

训练流程可概括为以下步骤。

1. 从各数据集选择一个相机视角，并统一图像分辨率。
2. 将语言任务描述与图像或图像历史一起输入策略。
3. 将原始动作转换为七维末端执行器表示。
4. 按数据集归一化动作，再将动作离散化为 token。
5. 联合训练模型，执行时按目标平台解释和反归一化动作。

七维动作包括 x、y、z、roll、pitch、yaw 和夹爪开合。模型输出还包含终止执行的维度，论文将动作按每维 256 个区间进行离散化。

这种对齐保留了不同数据集的控制语义。各平台的动作可以表示绝对位置、相对位移或速度，坐标系也存在差异。因此，同一个数值向量在不同机器人上可能产生不同运动。

### 4.2 RT-1-X 与 RT-2-X

| 维度 | RT-1-X | RT-2-X |
| --- | --- | --- |
| 基础架构 | RT-1 | RT-2-PaLI-X |
| 模型组成 | EfficientNet、语言嵌入、FiLM 和 Transformer | 视觉编码器与语言模型 |
| 参数规模 | 约 35M | 实验包含 5B、55B |
| 动作输出 | 离散动作 token | 表示动作的文本 token |
| 训练数据 | 机器人混合数据 | 机器人数据与视觉语言数据联合微调 |
| 实验部署 | 本地运行 | 云端服务，经网络调用 |

两条路线都基于已有机器人策略架构扩展跨平台训练。RT-2-X 将动作作为一种可预测的 token 序列，使视觉语言模型能够接受机器人控制监督。其主实验联合微调时，原视觉语言数据与机器人数据约按 1∶1 混合。

### 4.3 训练目标

模型通过模仿示范中的动作学习策略，使用离散输出上的分类交叉熵损失。训练信号来自给定图像和任务指令下的示范动作。

本节对应论文 §IV。

## 5. 实验结果

论文共开展约 3,600 次评估，涉及 6 种机器人，重点考察已有任务表现、跨平台技能迁移和设计因素。

### 5.1 小数据平台的正迁移

在 5 个小数据领域中，RT-1-X 在 4 个领域超过各数据集原有方法。论文报告，其平均成功率相对原方法或单数据集 RT-1 提高约 50%。

这里的 50% 是相对增幅。例如，从 40% 提高到 60% 对应相对提高 50%，增加 20 个百分点。该例仅用于解释统计口径。

同架构 RT-1 与 RT-1-X 的比较，使混合数据训练的贡献更容易观察。结果支持数据较少的平台从其他机器人的经验中获益。

### 5.2 大数据平台对容量的要求

下表摘录原文 Table I。

| 方法 | Bridge / Stanford | Bridge / Berkeley | Google Robot 六类技能 |
| --- | --- | --- | --- |
| 单数据集 RT-1 | 40% | 30% | 92% |
| RT-1-X | 27% | 27% | 73% |
| RT-2-X 55B | 50% | 30% | 91% |

RT-1-X 在这些场景中的表现下降，作者将其解释为欠拟合。更大的 RT-2-X 在各场景中取得较强表现，其中两个场景与单数据集 RT-1 接近。

这些结果表明，联合训练收益受模型容量和具体评估场景影响。增加异构数据后，模型需要有足够能力吸收其多样性。

### 5.3 跨机器人技能迁移

实验在 Google Robot 上执行一组任务，相关物体和技能出现于另一种机器人 WidowX 的 Bridge 数据中，目标机器人的原训练数据缺少这些经验。

| 方法 | 跨机器人技能评估成功率 | 原 RT-2 泛化评估成功率 |
| --- | --- | --- |
| RT-2 55B | 27.3% | 62% |
| RT-2-X 55B | 75.8% | 61% |
| RT-2-X 55B，移除 Bridge | 42.8% | 54% |

跨机器人技能评估从 27.3% 提升至 75.8%，约为原来的 2.78 倍，论文概括为约 3 倍。移除 Bridge 后的下降支持其他平台数据对新增技能的贡献。

原 RT-2 泛化评估考察未见物体、背景与环境，两个主模型在这一维度表现接近。阅读“约 3 倍”时，应保留跨机器人技能评估这一适用范围。

### 5.4 消融实验

| 因素 | 主要观察 |
| --- | --- |
| 图像历史 | 5B 模型加入短图像历史后，技能与泛化评估均改善 |
| 视觉语言预训练 | 从头训练的 5B 模型在两项评估中仅达到 0% 和 1% |
| 模型规模 | 55B 模型在跨机器人技能评估中取得更高成功率 |
| Bridge 数据 | 移除后，跨机器人技能成功率下降 |
| 持续混合网页数据 | 在对应 5B 对照中，两项指标各有高低 |

这些结果支持预训练、历史信息和数据选择的重要性。不同规模模型的比较还涉及历史长度等配置差异，对容量因素的独立贡献仍需更严格的受控实验。

## 6. 贡献与局限

### 6.1 主要贡献

- **数据基础设施**。将分散的真实机器人经验整理为可共同使用的数据资源。
- **跨平台正迁移证据**。通过真实机器人实验验证联合训练的可行性。
- **技能迁移证据**。通过目标平台评估和移除 Bridge 的消融实验，分析其他机器人数据带来的收益。
- **可继续研究的资源**。提供数据使用工具和 RT-1-X 模型资源。

### 6.2 证据范围与开放问题

- **新机器人适应仍待研究**。论文将训练中未见机器人的泛化列为后续问题。
- **形态覆盖有限**。实验主要围绕操作任务，感知和驱动方式差异很大的平台仍需验证。
- **联合训练可能出现性能下降**。RT-1-X 的大数据场景结果显示容量与数据匹配的重要性。
- **数据分布存在偏斜**。不同机器人、技能和场景的覆盖程度不同，抓取放置类任务占比较高。
- **平台适配仍有工作量**。执行时需要正确处理动作含义、归一化参数和控制接口。
- **迁移条件缺少预测准则**。何种数据组合能够带来收益，是作者提出的开放问题之一。

本节对应论文 §III-B、§V 和 §VI。

## 7. 对具身数据平台的启示

以下为基于论文方法的工程解读。

### 7.1 保留动作语义元数据

统一数据字段后，还应能追溯机器人形态、相机配置、动作坐标系、单位、绝对量或增量语义、控制频率以及归一化参数。这些信息决定了训练输出能否被正确转换为平台动作。

### 7.2 记录训练数据混合版本

数据仓库包含哪些数据，与某次模型训练实际使用哪些数据，是两个需要分别记录的事实。可复现记录应覆盖数据来源、版本、过滤规则、采样权重和预处理配置。

### 7.3 分维度评估数据价值

数据价值可以通过目标平台已有任务、跨平台技能迁移、未见物体与场景泛化等指标分别衡量。新增轨迹数量与模型收益之间的关系，需要结合这些评估结果判断。

## 8. 总结

Open X-Embodiment 为跨机器人经验共享建立了数据基础，并通过 RT-X 实验展示了正迁移和技能迁移。结果同时说明，数据收益依赖模型容量、预训练基础和数据构成。

对于具身数据平台建设，论文提供的直接启示是，将数据格式、动作语义、训练混合版本和迁移效果共同纳入管理，才能持续评估共享数据的实际价值。
